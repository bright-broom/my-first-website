# my-first-website

Webサイト制作やブランディングを学ぶための、HTML/CSSによる小さなサイトです。

## ローカルで確認する

このフォルダで以下を実行し、`http://127.0.0.1:8765` を開きます。
Python 3 が必要です。終了するには Ctrl+C を押します。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

ビルドやパッケージのインストールは不要です。`index.html` を直接開くこともできます。

## 編集する場所

- 文章・ページタイトル・検索向け説明：`index.html`
- 色・フォント・横幅：`style.css` 冒頭の変数と `body`
- 文字サイズ・余白：`style.css` の各要素
- 問い合わせ先：`index.html` の Contact。現在は準備中です。公開用の連絡先が確定したらリンクに差し替えてください。

## 設計判断（2026-09-28、デザイン改訂）

「Small steps. New worlds.」をコンセプトに、学びと探求を表すエディトリアルデザインへ刷新しました。
アイボリー、コバルトブルー、濃いチャコールを軸に、大きな欧文見出しと細い罫線で情報の強弱をつくっています。
ヒーロー、自己紹介、学習分野、今後の案内という順に構成し、実績や問い合わせ先は捏造していません。

- 実装：既存の静的HTML/CSS。フレームワーク・JavaScript・追加依存なし。
- ガイド：共通フロントエンドガイドとカタログ（2026-09-14、版1.0）を参照。
- UI：標準HTMLによるナビゲーションとページ内リンク。今回の規模ではUIライブラリは不要。
- グラフィック：`index.html` 内のオリジナルSVG。球体と軌道は今回制作したもので、外部素材・CDNは使用していません。
- フォント：日本語は Noto Sans JP を優先し、未インストール環境はOSの日本語フォントへフォールバック。欧文見出しは Arial / Georgia。フォントファイルの外部通信なし。
- 動き：CSSによるリンクのホバーと滑らかなページ内移動。動きを減らす設定では無効化。
- 編集：色・幅・左右余白は `style.css` の変数、グラフィックは `index.html` のSVG、各セクションの文章は同HTMLで編集。

## 検証

2026-09-28、ローカルHTTP配信と Chromium 151.0.7922.34 で確認しました。

- 320 / 375 / 768 / 1024 / 1440 CSS px、および各幅でルート文字サイズ200%：横方向のはみ出しなし。
- 375 / 1440 CSS px：スクリーンショットでレイアウト・文字・改行を確認。本文は確認後に可読性のため拡大。
- アプリ内ブラウザで Tab → Enter による本文フォーカス移動、Exploreリンクによる移動を確認。
- アプリ内ブラウザのコンソールエラーなし。

ルート文字サイズ200%の検証はブラウザ全体のズームや全テキストの倍寸表示を保証するものではありません。
スマートフォン実機・Safari・スクリーンリーダー・本番配信は未検証です。
公開先の設定やデプロイはこの変更に含まれません。
